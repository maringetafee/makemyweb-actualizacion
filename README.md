# makemyweb-actualizacion

Prototipos de la nueva web de makemyweb.es (HTML/CSS/JS sin dependencias). No es el proyecto de producción.

- `nueva/`: diseño nuevo (rojo de marca, tinta, sombras duras, índice estático bajo el hero).
- `clasica/`: diseño oscuro anterior (marquee, brillos, degradados) con el mismo contenido actualizado.

Ambas llevan `noindex`. El formulario de contacto apunta a `/.netlify/functions/notify-lead`, que solo existe en la web oficial.
